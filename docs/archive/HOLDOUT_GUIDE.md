# Holdout Gold 操作指南

当前视频：`vid_a598228fbc11`，1993 帧，30 FPS，约 66.43 秒。

## 标注前检查

1. 打开 `http://localhost:3000/gold` 并刷新页面。
2. 页面顶部必须显示 `HOLDOUT VIDEO · vid_a598228fbc11`。
3. 右侧“已记录击球”必须从 0 开始；此视频使用独立浏览器存储，不读取第一段视频的 Gold。
4. 不打开 `data/runs/holdout-a598-v0.3/events.jsonl`，也不生成或观看机器 QA 叠加视频。

## 如何记录

- 空格：播放或暂停。
- `U`：远端（画面上方）球员击球。
- `L`：近端（画面下方）球员击球。
- `K`：确定发生击球，但无法判断是哪一侧球员。
- 左/右方向键：逐帧移动；Shift + 左/右：移动10帧。
- `R`：只有在上一分结束、下一次发球开始时，才开始新回合。
- Ctrl+Z：撤销上一次记录。

正常播放即可，不需要给每一帧打标签。看到击球后暂停，用逐帧键定位到视觉上最接近球拍触球的帧，然后按一次 U、L 或 K。

## 不确定度

- 清楚看到触球：保持“高、±1帧”。
- 大致确定但被运动模糊或遮挡：改为“中、±2到3帧”。
- 只能确定附近发生了击球：使用“低、±4到5帧”，并写简短备注。
- 不要为了接近任何预期数量而补标或删标；只按完整视频中实际看到的击球记录。

## 完成与导出

1. 播放到视频末尾。
2. 从右侧列表依次抽查击球，确认没有同一击球重复记录。
3. 确认回合切换只发生在两分之间。
4. 点击“导出 Gold CSV”。文件名应为 `vid_a598228fbc11.hits_gold.csv`。
5. 将导出的 CSV 交给 Codex；在此之前不会运行 holdout 评估，也不会修改 v0.3 参数。
