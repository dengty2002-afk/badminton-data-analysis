# v0.4 Validation Gold 操作指南

当前视频：`vid_576b0c1ab370`，1745帧，30 FPS，约58.17秒。

## 标注前检查

1. 打开 `http://localhost:3000/gold` 并刷新页面。
2. 页面顶部必须显示 `VALIDATION VIDEO · vid_576b0c1ab370`。
3. 右侧“已记录击球”必须从0开始；该视频使用独立浏览器存储。
4. 不打开 `data/runs/validation-576b-v0.4/events.jsonl`，不查看候选数量，也不生成机器QA叠加视频。

## 快捷键

- 空格：播放或暂停。
- `U`：远端、画面上方球员击球。
- `L`：近端、画面下方球员击球。
- `K`：确定发生击球，但无法判断球员。
- 左/右：逐帧；Shift + 左/右：移动10帧。
- `R`：上一分结束、下一次发球开始时切换新回合。
- Ctrl+Z：撤销上一次记录。

正常播放即可，不需要逐帧填写。看到击球后暂停，逐帧定位到视觉上最接近球拍触球的帧，然后只按一次 U、L 或 K。球衣颜色和运动员姓名不决定标签；永远按画面远端/近端判断。

## 不确定度

- 清楚看到触球：高、±1帧。
- 运动模糊或轻微遮挡：中、±2到3帧。
- 只能确定附近发生击球：低、±4到5帧，并写备注。

## 完成

1. 播放到视频末尾。
2. 检查同一击球是否被重复记录。
3. 确认回合切换只发生在两分之间。
4. 导出文件，正确文件名为 `vid_576b0c1ab370.hits_gold.csv`。
5. 将CSV交给Codex；Gold锁定前不会披露机器候选数量或结果，锁定后只评估一次且不在本视频上调参。
