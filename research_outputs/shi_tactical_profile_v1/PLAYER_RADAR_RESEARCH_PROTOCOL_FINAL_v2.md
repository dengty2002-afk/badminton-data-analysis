## 1. 研究决策

### 1.1 最终定位

研究类型：回顾性、观察性、单运动员、多比赛个案研究。

研究对象：石宇奇在 24 场男子单打比赛中的算法自动标注逐拍事件。

研究目标：构建可复现的“打法风格画像”和“技战术过程代理画像”，描述石宇奇在当前比赛样本中的击球构成、空间使用、事件节奏和序列结构，并与同场对手进行比赛级配对比较。

本研究不评价：

- 绝对竞技能力；
- 技术成功率或得分价值；
- 某种打法是否导致胜负；
- 世界级常模位置；
- 失误控制、真实空间控制或长回合韧性。

### 1.2 最终输出结构

主分析：

1. 八轴打法风格雷达；
2. 每个风格指标的比赛级原始值、95% CI 和同场配对差异；
3. 配对相对倾向分数，仅用于雷达显示；
4. 比赛间稳定性与敏感性分析。

次分析：

1. 五轴技战术过程代理图；
2. 前三拍结构、长回合暴露、落点覆盖和未分类率；
3. 对手分组和比赛偏离案例。

明确取消：

- 将当前五轴图命名为“能力雷达”；
- 将长回合参与率解释为多拍韧性；
- 将网前参与率解释为网前控制；
- 将回合末杀球比例解释为进攻终结成功；
- 将落点熵解释为空间控制；
- 将雷达面积或各轴平均值构造成综合能力总分。

## 3. 研究问题与分析目标

### 3.1 研究问题

RQ1：石宇奇在当前 24 场比赛中的球种、击球位置、事件频率、空间使用和击球序列结构如何？

RQ2：石宇奇与同场对手相比，哪些风格指标在多数比赛中呈现稳定的相对方向？

RQ3：石宇奇的风格指标在比赛之间有多大变异，是否受个别比赛、对手重复或分析口径影响？

RQ4：进攻进入、终局后场进攻、网前连续使用、防守转攻和前三拍结构能否形成透明、可复现的技战术过程代理？

RQ5：当前字段不能支持哪些比赛效果结论，需要增加哪些结果变量才能升级为真正的表现雷达？

### 3.2 假设状态

本研究不设置确认性方向假设，原因是全部 24 场数据已经用于 v1 先导分析。

v2 预先固定：

- 指标定义；
- 分析单位；
- 分母；
- 配对方式；
- 归一化方式；
- 缺失处理；
- 敏感性分析；
- 图表形式；
- 解释边界。

v2 结果只回答预先固定的估计问题，不使用 p < .05 作为主要判断标准。

### 3.3 主次结局

- 主要结局：八个打法风格指标的比赛等权均值、同场平均配对差和配对相对倾向分数；
- 次要结局：五个技战术过程代理、比赛间变异和长回合暴露；
- 敏感性结局：S1–S9 的方向、数值变化和 `STABLE/UNSTABLE` 状态；
- 不设单一综合结局，不用雷达面积或轴平均值替代上述结局。

## 4. 研究价值

### 4.1 实证价值

- 提供石宇奇 24 场比赛的比赛级风格基线；
- 将总体球种比例扩展到位置、节奏、空间和序列；
- 同时保留每场比赛变异，避免仅用 14,157 次事件汇总出一个表面精确的平均值；
- 可定位偏离个人基线的比赛，服务于视频复盘。

### 4.2 方法学价值

- 明确区分“风格”“过程代理”和“比赛效果”；
- 将逐拍事件先聚合到比赛层面，控制伪重复；
- 使用同场配对比较，减少不同比赛环境造成的不可比性；
- 同时报告原始值、不确定性和雷达分数，避免图形替代统计结果；
- 对组成数据、阈值选择、落点缺失和序列定义设置敏感性分析。

### 4.3 理论价值

本研究把单运动员画像拆成三个层级：

1. 使用结构：球种、位置、空间和节奏；
2. 过程结构：从一种击球状态进入另一种击球状态；
3. 结果效果：击球或序列与得分、失误和回合胜负的联系。

当前研究覆盖前两个层级，不跨越到第三层级。该区分与逐拍数据组织、技术战术观察和序列分析研究的基本逻辑一致。ShuttleSet 证明了逐拍球种、击球位置、双方位置和落点可被组织为统一的战术分析数据结构；技术战术观察工具则进一步说明，结果变量是评价效果不可缺少的部分。[ShuttleSet](https://doi.org/10.1145/3580305.3599906)；[单打技术战术观察工具](https://doi.org/10.3389/fpsyg.2020.582693)。

### 4.4 可发表性边界

当前数据足以支持：

- 单运动员多比赛个案研究；
- 技战术风格画像；
- 比赛间稳定性研究；
- 自动逐拍数据的分析框架应用研究。

当前数据不足以支持：

- 经验证的球员能力量表；
- 得分效果模型；
- 失误控制评价；
- 世界级球员常模；
- 胜负预测或因果推断。

论文价值取决于指标透明性、比赛级不确定性、敏感性分析和解释边界，而不取决于雷达图是否“看起来完整”。

### 5.2 推断总体

主要推断对象是“纳入的 24 场比赛”，属于有限样本描述。

对石宇奇未来比赛、全部职业男子单打比赛或世界排名球员的外推均为探索性推断，不作为主要结论。

### 5.3 样本量与精度

本研究由现有完整比赛决定样本量，不实施事后功效分析。有效独立分析单位最多为 24 个比赛配对，而不是 14,157 次逐拍事件。

- 配对相对倾向分数每增加或减少 1 场，变化约为 `100/24 = 4.17` 分；
- Bootstrap 区间反映 24 场比赛内的不确定性，不能消除样本覆盖有限和对手重复的问题；
- 当某指标有效比赛少于 18 场时，不进入主雷达；
- 结果重点报告估计值、区间宽度和方向一致性，不以“样本显著”为研究成功标准。

### 5.4 自动标注假设

按本项目要求，本研究不进行人工复核，也不评估自动标注准确率。

所有结论必须写成：

“基于当前算法标注数据得到的画像”。

不得写成：

“石宇奇真实比赛行为的无误差测量”。

自动标注可靠性不是本研究问题，但算法输出与真实行为的差异仍属于外部解释边界。

## 6. 纳入、排除与数据质量规则

### 6.1 比赛纳入

一场比赛必须同时满足：

1. `identity_mapping.csv` 中存在唯一 `video_id`；
2. `shi_side` 为 `upper` 或 `lower`；
3. 对应 `dataset_rows.csv` 存在且非空；
4. 至少存在一个石宇奇事件和一个对手事件；
5. `video_id` 在整个映射表中唯一。

任一条件不满足：停止主分析并生成错误报告，不静默跳过。

### 6.2 事件处理

| 情况 | 处理 |
|---|---|
| player 不是 upper/lower | 从球员比较中排除，保留排除计数 |
| event_id 重复 | 保留第一条前先检查内容；内容不一致则停止运行 |
| rally_id 缺失 | 可用于总体事件比例；从回合、节奏和序列指标排除 |
| stroke_index 缺失 | 以 hit_time 排序；从前三拍分析排除 |
| hit_time 缺失或回合时长 ≤ 0 | 从节奏指标排除 |
| 坐标超出 6.1 m × 13.4 m | 设为缺失，不裁剪到边界 |
| stroke_type = unknown | 保留在总事件和缺失率；从主要球种比例分母排除 |
| 落点无效 | 从落点指标排除，不插补 |

### 6.3 必做质量检查

每次运行必须输出：

- 比赛数和每场双方事件数；
- 石宇奇/对手是否严格成对；
- event_id 重复数；
- rally_id 缺失数；
- stroke_index 缺失、重复和非单调回合数；
- hit_time 缺失和非正时长回合数；
- 非法坐标数；
- 各比赛已分类率、位置有效率和落点有效率；
- 各指标有效分母的最小值、中位数和最大值。

运行开始时还必须对以下输入生成 SHA-256，并写入 `input_manifest.json`：

- `identity_mapping.csv`；
- 24 个 `dataset_rows.csv`；
- v2 脚本；
- 本协议文件。

后续重跑只有在输入哈希一致时才属于同一数据版本。

### 6.4 低分母规则

主要估计不因低分母自动删除比赛，以避免选择性排除；但以下情况标记为 `LOW_N`：

| 指标类型 | 每场警戒阈值 |
|---|---:|
| 球种比例 | 已分类击球 < 50 |
| 击球位置 | 有效自身位置 < 50 |
| 落点熵 | 有效落点 < 50 |
| 横向位移熵 | 有效 own_x 与 landing_x < 50 |
| 节奏 | 有效回合 < 30 |
| 序列 | 有效转移对 < 50 |
| 过程转移代理 | 有效机会 < 20 |

如果某指标有效比赛少于 18 场：

- 不进入主雷达；
- 结果写为 NA；
- 可在附录中报告探索性结果。

## 7. 分析单位、权重与主要估计量

### 7.1 层级

数据层级：

事件 → 回合 → 比赛 → 运动员总体画像。

### 7.2 主要权重

每场比赛权重相同。

主要总体值：

~~~text
overall_metric = mean(match_metric_1, ..., match_metric_M)
~~~

这样可避免长比赛因事件更多而主导总体画像。

事件合并后的 pooled estimate 只作为敏感性分析。

### 7.3 配对比较

每场比赛计算：

~~~text
d_m = Shi_metric_m - Opponent_metric_m
~~~

主要报告：

- 石宇奇比赛级均值和中位数；
- 对手比赛级均值和中位数；
- 平均配对差 `mean(d_m)`；
- 配对差 95% Bootstrap CI；
- 配对相对倾向分数；
- 有效比赛数和底层事件/回合分母。

### 7.4 不确定性

- 重抽样单位：比赛；
- 重复次数：10,000；
- 固定随机种子：20260822；
- 区间：Bootstrap percentile 95% CI；
- 配对分析：每次同时抽取同一比赛的石宇奇和对手记录；
- 对手聚类 Bootstrap 作为敏感性分析。

不把逐拍事件当作 14,157 个独立运动员样本。

## 8. 打法风格主雷达

### 8.1 八个固定轴

| 顺序 | 轴 | 变量名 | 操作化定义 | 解释 |
|---:|---|---|---|---|
| 1 | 杀球倾向 | `smash_share` | (smash + wrist smash) / 已分类击球 | 使用频率 |
| 2 | 吊球倾向 | `drop_share` | (drop + passive drop) / 已分类击球 | 使用频率 |
| 3 | 网前倾向 | `net_share` | 网前/前场宏观类别 / 已分类击球 | 使用频率 |
| 4 | 抽挡倾向 | `drive_share` | 平抽/推挡宏观类别 / 已分类击球 | 使用频率 |
| 5 | 后场击球倾向 | `backcourt_tendency` | own_depth = 后场 / 有效自身位置 | 击球位置结构 |
| 6 | 事件频率代理 | `event_rate_proxy` | 每回合石宇奇事件数/回合持续时间的比赛级中位数 | 事件节奏，不是移动速度 |
| 7 | 空间使用多样性 | `spatial_diversity` | 0.5 × 落点熵 + 0.5 × 横向位移熵 | 使用分散度，不是空间控制 |
| 8 | 序列可预测性熵代理 | `sequence_predictability` | 1 − 六类自有击球转移的归一化条件熵 | 转移集中度，不是对手真实预测准确率 |

六类球种映射固定如下；未列出的值统一记为 `unknown`：

| 宏观类别 | 原始 `stroke_type` |
|---|---|
| 发球 | `short service`, `long service` |
| 网前/前场 | `net shot`, `return net`, `rush`, `cross-court net shot` |
| 后场进攻 | `smash`, `wrist smash` |
| 高远/挑球 | `lob`, `defensive return lob`, `clear` |
| 平抽/推挡 | `drive`, `defensive return drive`, `back-court drive`, `push` |
| 吊球 | `drop`, `passive drop` |

其中：

- `smash_share` 只使用 `smash` 和 `wrist smash`；
- `drop_share` 只使用 `drop` 和 `passive drop`；
- `net_share` 和 `drive_share` 使用上表对应的完整宏观类别；
- 四项比例的共同分母为六类已分类击球总数，发球和高远/挑球留在分母中；
- 映射在 v2 执行期间不得根据结果修改。

纵深区域按运动员所在半场到球网的归一化距离划分：距本方底线不足半场长度的 `1/3` 为后场，`1/3–2/3` 为中场，`2/3–1` 为前场。宽度按场宽三等分。边界规则固定为左闭右开，最外侧终点闭合。

### 8.2 空间指标

落点熵：

~~~text
H_landing = -Σ p(z) ln p(z) / ln(9)
~~~

横向位移：

~~~text
delta_x = landing_x - own_x
~~~

主分类阈值：

- 左偏：`delta_x < -court_width/6`；
- 中路：`|delta_x| ≤ court_width/6`；
- 右偏：`delta_x > court_width/6`。

横向位移熵：

~~~text
H_lateral = -Σ p(c) ln p(c) / ln(3)
~~~

只有当同一场比赛的 `H_landing` 和 `H_lateral` 均有效时才计算组合指标。不得用单一有效分量替代两者平均。

### 8.3 序列指标

主要序列：

- 以“比赛 × 回合 × 运动员”为边界；
- 只使用该运动员的已分类击球；
- 按 `stroke_index`、`hit_time`、`event_id` 排序；
- 不跨回合连接；
- `unknown` 作为序列断点，不连接其前后的已分类击球；
- 相邻两次该运动员击球构成一个转移对。

~~~text
H_transition =
-Σ p(source=i) Σ p(target=j | source=i) ln p(j|i)

sequence_predictability =
1 - H_transition / ln(6)
~~~

名称中必须保留“熵代理”。不得把它直接解释为对手预测石宇奇下一拍的准确率。

### 8.4 事件频率代理

对每个至少含两条有效 `hit_time` 且持续时间大于 0 的回合：

~~~text
rally_duration = max(all_hit_time) - min(all_hit_time)
player_event_rate = n_player_events / rally_duration
~~~

比赛级 `event_rate_proxy` 是该运动员所有有效回合 `player_event_rate` 的中位数。双方使用同一回合持续时间。它只表示事件记录频率，不表示步频、移动速度、反应时或真实击球间隔。

### 8.5 组成约束

杀球、吊球、网前和抽挡比例来自同一个完整球种构成，彼此不独立。

处理规则：

- 雷达只展示，不对四个比例分别作优劣排序；
- 主文同时报告完整六类构成；
- 使用六类 JSD 描述整体差异；
- 使用 CLR 变换作敏感性分析；
- CLR 零计数加固定 0.5 计数后闭合到 1。

组成数据需要按比例整体解释，而不是把每个比例当成相互独立的连续变量。[Aitchison 的组成数据方法](https://doi.org/10.1111/j.2517-6161.1982.tb01195.x)。

## 9. 技战术过程代理图

该图回答“当前字段能观察到哪些过程结构”，不回答“能力有多强”。

### 9.1 状态定义

主状态映射：

| 状态 | 纳入类别 |
|---|---|
| 进攻 | 后场进攻：smash、wrist smash |
| 防守/重置 | 高远/挑球 |
| 中性组织 | 网前/前场、平抽/推挡、吊球 |
| 发球 | 单独保留，不作为进攻构建机会 |
| 未分类 | 不进入状态转移 |

敏感性分析的宽口径进攻状态额外加入 raw stroke_type = rush。

### 9.2 五个固定代理

| 顺序 | 指标 | 变量名 | 主要定义 | 禁止解释 |
|---:|---|---|---|---|
| 1 | 前三拍主动类别比例 | `early_active_share` | stroke_index ≤ 3 的已分类击球中，进攻、网前/前场和平抽/推挡的比例 | 开局得分能力、接发质量 |
| 2 | 进攻进入代理 | `attack_entry_proxy` | 含中性/防守事件的回合中，后续 1–2 次石宇奇击球内出现后场进攻的回合比例 | 进攻构建成功率 |
| 3 | 终局后场进攻事件比例 | `terminal_attack_event_share` | 全回合最后观测事件属于石宇奇且为后场进攻的回合 / 可识别最后事件回合 | 杀球得分率、终结成功率 |
| 4 | 网前连续使用代理 | `net_continuation_proxy` | 网前/前场击球后 1–2 次石宇奇已分类击球内再次出现网前/前场的机会比例 | 网前控制能力 |
| 5 | 防守转攻代理 | `defense_to_attack_proxy` | 含高远/挑球事件的回合中，后续 1–2 次石宇奇击球内出现后场进攻的回合比例 | 防守转攻后的赢球率 |

过程代理的计算边界固定如下：

1. 每个回合先按 `stroke_index`、`hit_time`、`event_id` 排序；同键冲突时停止运行，不任意打破冲突。
2. `early_active_share` 的“前三拍”指全回合 `stroke_index ≤ 3`，不是运动员个人前三次击球；分母为其中该运动员的六类已分类击球。
3. `attack_entry_proxy` 的分母为至少存在一个“中性组织或防守/重置锚点”，且锚点后的 1–2 次自有原始事件中至少有一次可分类事件的回合。若任一合格锚点后的第 1 或第 2 次自有原始事件为后场进攻，该回合记为 1，否则为 0；每回合最多计一次。
4. `terminal_attack_event_share` 先从双方全部有效事件确定全回合最后事件。最后事件的 `player` 和宏观类别均可识别时进入分母；该事件属于目标运动员且类别为后场进攻时记为 1，否则为 0。
5. `net_continuation_proxy` 的分析单位为网前/前场锚点。锚点后的 1–2 次自有原始事件中至少有一次可分类事件才进入分母；其中任一事件再次为网前/前场时记为 1。
6. `defense_to_attack_proxy` 与进攻进入代理相同，以回合为单位，但锚点只限高远/挑球；每回合最多计一次。
7. 跨回合不连接；`unknown` 不作为状态，但会占用“后续 1–2 次自有事件”的位置，不把隔着 `unknown` 的两拍误写成原始相邻事件。

### 9.3 不进入过程图的指标

| 指标 | 处理 | 原因 |
|---|---|---|
| 长回合参与率 | 辅助表 | 对同一回合的双方相同，不能形成球员配对差异 |
| 长回合韧性 | NA | 缺少长回合胜负 |
| 失误控制 | NA | 缺少 forced/unforced error |
| 空间控制 | NA | 缺少落点效果和对手被动状态 |
| 发球/接发效果 | NA | 缺少 server 和 rally_winner |
| 主动性 | 探索性辅助 | 仅凭球种类别推断主动/被动，构念效度不足 |

长回合研究通常同时使用回合时间、击球间隔、击球数和回合结果；只有击球数不能被直接称为韧性。[长回合研究](https://doi.org/10.1371/journal.pone.0229604)。

## 10. 雷达显示分数

### 10.1 主要统计结果不是雷达分数

论文主要结果依次为：

1. 原始比赛级均值；
2. 95% CI；
3. 同场配对差；
4. 配对差 CI；
5. 有效分母；
6. 配对相对倾向分数。

### 10.2 最终显示分数

对每个可以配对的指标：

~~~text
score_k =
100 × [Σ I(d_m > 0) + 0.5 × Σ I(d_m = 0)] / M_valid
~~~

含义：

- 0：所有有效比赛中石宇奇都低于同场对手；
- 50：高于和低于对手的比赛数大致相等；
- 100：所有有效比赛中石宇奇都高于同场对手。

对于风格指标，“高于”表示该倾向更强，不表示表现更好。

显示分数的 95% CI 使用比赛级配对 Bootstrap。

### 10.3 取消 P05–P95 截断

v2 不再使用：

~~~text
100 × clip((value - peer_P05) / (peer_P95 - peer_P05), 0, 1)
~~~

原因：

- 24 个对手比赛值不足以形成稳定常模；
- P05 和 P95 对样本组成敏感；
- 截断会把不同程度的极端值压成相同的 0 或 100；
- 可能出现显示分数较高但配对差 CI 跨 0 的情况。

### 10.4 图形规则

- 固定轴顺序，不因结果重新排序；
- 只画线和数据点，不填充多边形面积；
- 显示 50 分参考环；
- 每个轴标注有效比赛数；
- 图注写明“相对倾向，不是绝对能力”；
- 不计算雷达面积；
- 不计算八轴平均总分；
- 主文同时提供线性区间图或点图。

雷达图用于多维摘要，但比较精度和面积解释存在局限，因此必须与原始表和线性图同时出现。[体育分析中的增强雷达图](https://doi.org/10.1177/17479541221099638)；[填充雷达图的比较风险](https://doi.org/10.1007/s11205-012-0028-6)。

## 11. 统计分析

### 11.1 描述统计

每个指标报告：

- 比赛级均值；
- 比赛级中位数；
- SD；
- IQR；
- 最小值和最大值；
- 95% Bootstrap CI；
- 有效比赛数；
- 底层事件、回合或机会数。

### 11.2 配对比较

每场比赛以石宇奇和同场对手组成一对。

报告：

- 平均配对差；
- 配对差中位数；
- 配对差 95% CI；
- 配对相对倾向分数及 CI；
- 24 条比赛级差值散点或坡度图。

不把“CI 跨 0”写成“完全没有差异”；写成“当前样本下方向不稳定或估计精度不足”。

### 11.3 比赛间稳定性

使用：

- 比赛级 IQR；
- 中位绝对偏差；
- 与个人总体六类构成的 JSD；
- leave-one-match-out 影响值；
- 单场指标与总体均值的绝对偏差。

不使用 ICC 作为主要稳定性指标，因为比赛对手和情境不同，不是同条件重复测量。

### 11.4 对手重复

17 名对手中存在重复交手。

主要分析仍以比赛配对为单位；敏感性分析以对手为聚类单位重抽样。

对手级结果只有在：

- 至少 2 场交手时报告；
- 至少 3 场交手时才讨论“对该对手的重复模式”；
- 少于 3 场不得称为稳定对手策略。

### 11.5 多指标问题

本研究不进行大规模显著性检验，不设置单一 p 值阈值。

如目标期刊要求检验：

- 使用配对检验；
- 同一指标族采用 Holm 校正；
- 同时报告效应量和 CI；
- 检验放在补充材料，不改变描述性主结论。

## 12. 必做敏感性分析

| 编号 | 问题 | 主口径 | 敏感性口径 | 稳定性判断 |
|---:|---|---|---|---|
| S1 | 比赛长度不等 | 比赛等权均值 | 全事件 pooled estimate | 配对方向一致；0–1 指标绝对变化 ≤0.10，事件频率相对变化 ≤20% |
| S2 | unknown 分母 | 排除 unknown | unknown 作为第七类；另报分类率 | 核心构成结论不反转 |
| S3 | 长回合阈值 | ≥10 拍 | ≥8、≥12 拍 | 只影响辅助描述，不改变能力解释 |
| S4 | 横向位移分箱 | ±场宽/6 | ±场宽/8、±场宽/4 | 空间多样性变化 < 0.10 |
| S5 | 序列定义 | 六类自有序列 | 原始球种序列；留一比赛下一类预测准确率 | 集中/分散方向一致 |
| S6 | 进攻状态 | 后场进攻 | 后场进攻 + rush | 过程代理方向一致 |
| S7 | 落点完整性 | 全部有效落点 | 每场落点有效率 ≥30%；每场有效落点 ≥50 | 估计变化 < 0.10 |
| S8 | 重复对手 | 比赛 Bootstrap | 对手聚类 Bootstrap | 配对差方向一致 |
| S9 | 单场影响 | 全部 24 场 | leave-one-match-out | 删除任一比赛不改变核心结论方向 |

某指标满足任一条件时标记为 `UNSTABLE`：

- 主口径与任一关键敏感性口径方向相反；
- 雷达分数变化超过 15 分；
- 比例或熵的绝对变化超过 0.10；
- 删除单场比赛后结论方向改变；
- 有效比赛少于 18。

`UNSTABLE` 指标不得作为摘要中的主要发现。

## 17. 研究停止和降级规则

出现以下情况时停止主分析：

- 任一比赛身份映射无法确定；
- 基础计数与锁定版本不一致且无法解释；
- 比赛配对失败；
- 重跑数值不一致；
- 指标公式与 `protocol_lock.json` 不一致。

出现以下情况时降级为附录：

- 有效比赛 < 18；
- 指标标记为 `UNSTABLE`；
- 空间指标对完整案例限制明显敏感；
- 过程代理在宽/窄状态定义下方向相反；
- 图形无法由表格数值复现。

## 18. 未来升级为比赛效果雷达

真正的八轴效果雷达至少需要：

| 字段 | 对应轴 |
|---|---|
| server | 开局与接发 |
| rally_winner | 所有效果轴 |
| score_before_rally | 关键分与比分情境 |
| point_end_type | 进攻终结、失误控制 |
| forced_error / unforced_error / winner | 失误控制和进攻效果 |
| last_hitter | 终局责任 |
| actual_landing_validity | 空间效果 |
| opponent_response_state | 网前控制、空间控制 |
| initiative_state | 进攻构建、防守转攻 |

加入这些字段后，可考虑：

- 发球/接发回合胜率；
- 进攻进入后的回合胜率；
- 终局进攻得分率；
- 网前序列后的回合胜率；
- 防守转攻后的回合胜率；
- 长回合胜率；
- 反向非受迫失误率；
- 落点导致对手被动或失分的概率。

基于结果状态的 Markov/EPV 模型和 perturbation–follow-up–survival–convert 结构应放在结果增强阶段，而不是当前 v2。[Markov/EPV 羽毛球序列研究](https://doi.org/10.1016/j.chaos.2022.112828)；[羽毛球动力系统分析](https://doi.org/10.1080/02640414.2024.2323327)。

未来新增且未被 v1/v2 查看过的比赛，应作为外部验证集，检验：

- 指标均值是否落入当前 CI；
- 轴方向是否保持；
- 配对相对倾向是否复现；
- 雷达形状是否对样本更新稳定。

## 19. 版本控制规则

以下内容在 v2.0 中锁定：

- 研究问题；
- 八个风格轴；
- 五个过程代理；
- 状态映射；
- 比赛等权；
- 配对差定义；
- 雷达分数公式；
- Bootstrap 单位、次数和种子；
- 低分母阈值；
- S1–S9；
- 图形轴顺序；
- 允许和禁止的结论语言。

任何结果驱动的修改必须：

1. 新建 v2.1；
2. 写明修改时间和原因；
3. 保留 v2.0 输出；
4. 将修改后的结果标记为探索性；
5. 不用新结果替换已锁定的主分析。

## 20. 最终执行判定

本研究可以继续执行，最终论文应定位为：

**基于自动逐拍数据的石宇奇男子单打打法风格与技战术过程画像：24 场比赛的回顾性个案研究。**

论文的主要贡献是：

- 一套与当前字段一致的球员画像指标；
- 比赛级配对和不确定性分析；
- 对雷达可视化误读的控制；
- 风格、过程代理和结果效果的明确分层；
- 可复现、可扩展到未来结果字段的研究流程。

成功标准不是得到“漂亮的能力雷达”，而是所有指标均有明确分母、可重复计算、对分析口径足够稳定，并且论文结论不超过数据实际支持的范围。
